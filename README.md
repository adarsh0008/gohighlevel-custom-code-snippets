## 🚀 How to use

1. Open the snippet file and copy the full code.
2. In GoHighLevel, open your **Funnel or Website → Settings → Tracking Code → Footer Code**, or drag a **Custom JS/HTML** element onto the page.
3. Paste the code, change the settings at the top (text, phone number, links, duration), save and **preview**.

### Tip: URL autofill with GHL forms
The autofill snippet matches the field's `name`. Standard GHL fields use names like `first_name`, `last_name`, `email` and `phone`. For UTM capture, add **hidden fields** to your form whose names are `utm_source`, `utm_medium`, `utm_campaign`, etc.

Example link: `https://yourfunnel.com/offer?first_name=John&email=john@example.com&utm_source=facebook`
